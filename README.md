# 봉 룰렛 (Bong Roulette)

http://bongroulette.com/

이름을 입력하고 콜로세움·레이스·문 선택·폭탄 돌리기 중 하나를 선택해 시작합니다.

- 콜로세움·레이스·폭탄 돌리기는 3D, 문 선택은 2D로 표시합니다.
- 문 선택: `!왼` / `!오` 채팅으로 문을 열고 구슬이 무작위 생존 경로와 용암으로 떨어지는 개인전입니다. 길은 카메라가 아래로 내려가면서 공개됩니다.
- SOOP 채팅 API는 승인 대기 상태입니다. 현재는 문 선택 모드의 시험 입력 버튼/입력창 또는 `문 설정 · 체험`의 `자동 채팅 체험`으로 진행할 수 있습니다.
- 기본 문 열림 0.4초, 대기 구슬이 많을수록 개방 시간 증가. 생존 받침은 카메라가 다음 갈림길에 도착한 뒤 열립니다.
- 진행 중 일시정지·재개와 2D/3D 전환, 화질 조절을 지원합니다.
- 콜로세움 1대1: 체력 3배 회복, 발동형 스킬 쿨타임 절반, 상시 스킬 피해 2배.
- 레이스 1대1: 두 바퀴 승부.
- 인터넷 없이 실행하려면 index.html과 colosseum3d.bundle.js를 같은 폴더에 두고 브라우저에서 index.html을 여세요.

Three.js 라이선스는 THREE-LICENSE.txt에 포함되어 있습니다.

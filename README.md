# 봉 룰렛 (Bong Roulette)

https://bongroulette.com

이름을 입력하고 콜로세움·레이스·블랙홀·폭탄 돌리기 중 하나를 선택해 시작합니다.

- 콜로세움·레이스·폭탄 돌리기는 3D, 블랙홀은 2D로 표시합니다.
- 진행 중 일시정지·재개와 2D/3D 전환, 화질 조절을 지원합니다.
- 콜로세움 1대1: 체력 3배 회복, 발동형 스킬 쿨타임 절반, 상시 스킬 피해 2배.
- 레이스 1대1: 두 바퀴 승부.
- 인터넷 없이 실행하려면 index.html과 colosseum3d.bundle.js를 같은 폴더에 두고 브라우저에서 index.html을 여세요.

Three.js 라이선스는 THREE-LICENSE.txt에 포함되어 있습니다.
